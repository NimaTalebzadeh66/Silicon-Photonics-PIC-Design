# Experimental PIC figures

Original figure files uploaded by the project author are intended to appear in the README alongside retained simulation and layout images:

- `mzi_measured_transmission.png` — measured MZI spectrum (with close-up)
- `ring_measured_transmission.png` — measured microring spectrum
- `bragg_reflector_sem.png` — fabricated Bragg grating SEM, image credited to Applied NanoTools
- `bragg_grating_layout_detail.png` — Bragg layout detail

The four files are supplied separately in `PIC_GitHub_Experimental_Images.zip` and should be uploaded to this directory on the feature branch before merging the draft pull request.
