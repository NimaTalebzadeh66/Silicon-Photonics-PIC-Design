## Characterization status

The author reports university-led fabrication and optical characterization. The repository does **not** yet include calibrated measured output-port powers, so it would be premature to claim a measured splitting ratio, excess loss, or usable bandwidth.

A future quantitative comparison should use simultaneous wavelength-matched port measurements, reference normalization, and a stated imbalance/bandwidth specification.
